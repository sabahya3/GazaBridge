# GazaBridge branding

- `logo-mark.svg`: the app icon. The Palestinian flag, crossed by a bridge
  whose central pier is a database. Regenerate the desktop icons with
  `python3 scripts/generate-icons.py` (needs `rsvg-convert`).
- Interface icons are a subset of [Lucide](https://lucide.dev) (ISC
  licence), inlined in `apps/desktop/ui/src/icons.rs`.
